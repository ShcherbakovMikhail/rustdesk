Sintec.RD — корпоративная сборка приложения удалённого доступа на базе [RustDesk](https://github.com/rustdesk/rustdesk). В сборке настроены сервер организации и его публичный ключ, изменены оформление и установщики. Для Windows доступны клиент EXE/MSI и Enterprise Agent.
